# SoapList — Vertical Mini-Drama Directory & Spotlight

SoapList is a premier entertainment directory and spotlight stage for vertical short-drama streaming applications (ReelShort, DramaBox, ShortMax, Sereal+, GoodShort, and more).

## Overview

- **Curated Directory**: Indexed vertical drama platforms categorized by genre (Billionaire Romance, Werewolf/Alpha, Revenge, Thriller).
- **Cinematic Theater Showcase**: 3D circular carousel featuring top-ranked mini-drama streaming apps.
- **Direct App Store & Google Play Routing**: Verified links to official mobile app stores with authentic high-res key-art.
- **Publisher Sponsorship Portal**: Tiered placements (Standard Spotlight and Premium Featured Hero).
- **Admin Control Console**: Curate spotlight slots, inspect Google Play Scraper payloads, and run live App Store discovery scans.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
